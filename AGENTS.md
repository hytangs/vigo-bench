# Public VIGO Bench

This repository owns the reusable coordinate benchmark harness, adapters,
dashboard, documentation and synthetic tests. Engine and Python-wrapper defects
belong in their respective repositories.

Never commit city inputs, raw benchmark results, private paper drafts, credentials,
runtime binaries or machine logs. Keep local evidence in ignored directories or
a separate private store. Review publication artifacts and their history.

Keep successful itineraries, no-itinerary outcomes, setup failures, query errors
and unsubmitted requests distinct. Report timing at its actual measurement
boundary. Synthetic tests are not evidence of city performance or correctness.

Run `npm ci --ignore-scripts` and `npm test` for source changes. Preserve existing
uncommitted work and never overwrite frozen evidence to make checks pass.
